# 动画资源说明

本目录存放3D宠物的骨骼动画文件。

## ⚠️ 重要说明

**动画文件（.glb）是二进制3D格式，无法通过代码直接生成。** 您需要：
1. 使用3D建模软件（如 Blender）创建动画
2. 从在线资源下载预制动画
3. 使用 Mixamo 等自动骨骼绑定服务

在没有真实动画文件时，应用会使用内置的程序化动画作为占位符。

## 技术规格

### 文件格式
- **格式**: GLTF 2.0 Binary (.glb)
- **包含**: 仅动画数据（不含模型几何体）
- **大小**: 建议 < 500KB/文件

### 动画参数
- **帧率**: 30 FPS（与渲染帧率匹配）
- **采样**: 建议使用线性插值
- **压缩**: 启用 Draco 压缩（可选）

### 时长建议

| 动画类型 | 建议时长 | 说明 |
|----------|----------|------|
| 循环动画 | 2-4秒 | idle, thinking, listening 等 |
| 单次动画 | 1-2秒 | celebrating |
| 过渡动画 | 0.3-0.5秒 | 状态切换混合时间 |

### 骨骼要求

动画必须与 `assets/models/default-pet.glb` 的骨骼结构兼容：

```
Root
└── Hips
    ├── Spine
    │   └── Spine1
    │       └── Spine2
    │           ├── Neck → Head
    │           │         ├── LeftEye
    │           │         ├── RightEye
    │           │         ├── LeftEar (可选)
    │           │         └── RightEar (可选)
    │           ├── LeftShoulder → LeftArm → LeftForeArm → LeftHand
    │           └── RightShoulder → RightArm → RightForeArm → RightHand
    ├── LeftUpLeg → LeftLeg → LeftFoot → LeftToeBase
    ├── RightUpLeg → RightLeg → RightFoot → RightToeBase
    └── Tail (可选)
```

## 各动画详细要求

### idle.glb - 待机动画
- **用途**: 无交互时的默认状态
- **表现**: 轻微呼吸起伏、耳朵/尾巴微动、偶尔眨眼
- **情绪**: 放松、平和
- **时长**: 3-4秒循环

### happy.glb - 开心动画
- **用途**: 收到好消息、用户点击反馈
- **表现**: 跳跃、摇尾巴、耳朵竖起
- **情绪**: 兴奋、愉悦
- **时长**: 2-3秒循环

### sad.glb - 难过动画
- **用途**: 坏消息、操作失败
- **表现**: 低头、耳朵下垂、尾巴低垂
- **情绪**: 失落、沮丧
- **时长**: 2-3秒循环

### thinking.glb - 思考动画
- **用途**: AI 正在处理请求
- **表现**: 歪头、眼睛看向上方、前爪抬起
- **情绪**: 专注、思索
- **时长**: 2秒循环

### confused.glb - 困惑动画
- **用途**: 无法理解用户请求
- **表现**: 歪头、耳朵交替动、挠头
- **情绪**: 疑惑、不解
- **时长**: 2秒循环

### drag.glb - 拖拽动画
- **用途**: 用户拖动宠物移动时
- **表现**: 四肢悬空、身体轻微摆动
- **情绪**: 被提起的感觉
- **时长**: 1秒循环

### listening.glb - 倾听动画
- **用途**: 语音输入激活时
- **表现**: 耳朵竖起转动、头部微倾、专注表情
- **情绪**: 专注倾听
- **时长**: 2秒循环

### celebrating.glb - 庆祝动画
- **用途**: 任务完成、成功提示
- **表现**: 跳跃、旋转、欢呼姿势
- **情绪**: 欢庆、胜利
- **时长**: 2秒（单次播放）

### sleepy.glb - 瞌睡动画
- **用途**: 长时间无用户交互
- **表现**: 打哈欠、眼睛半闭、身体下沉
- **情绪**: 困倦、放松
- **时长**: 4秒循环

### curious.glb - 好奇动画
- **用途**: 鼠标悬停、吸引注意
- **表现**: 耳朵竖起、头部追踪、眼睛睁大
- **情绪**: 好奇、警觉
- **时长**: 2秒循环

## 动画获取方式

### 方式1: Mixamo（推荐新手）
1. 访问 https://www.mixamo.com/
2. 上传您的角色模型（需要先有模型）
3. 选择合适的动画
4. 下载为 FBX 格式
5. 在 Blender 中转换为 GLB

### 方式2: 在线资源
- **Sketchfab**: https://sketchfab.com/search?type=animations
- **Quaternius**: https://quaternius.com/ （免费低多边形动画）
- **Kenney**: https://kenney.nl/ （游戏资源）
- **OpenGameArt**: https://opengameart.org/

### 方式3: Blender 自制
1. 导入模型文件
2. 切换到动画工作区
3. 创建动作（Action）
4. 设置关键帧
5. 导出为 GLB

## Blender 导出设置

### 仅导出动画（无模型）

```
导出 glTF 2.0 (.glb)
├── 格式: glTF Binary (.glb)
├── 内容:
│   ├── ☑ 动画
│   ├── ☐ 网格（取消勾选）
│   └── ☑ 骨架
├── 动画:
│   ├── ☑ 导出动画
│   ├── ☑ 烘焙所有动画
│   └── 采样率: 1（每帧）
└── 压缩: ☑ Draco 网格压缩
```

### 包含模型的动画导出

如果动画文件需要包含几何体：

```
导出 glTF 2.0 (.glb)
├── 格式: glTF Binary (.glb)
├── 内容:
│   ├── ☑ 动画
│   ├── ☑ 网格
│   ├── ☑ 材质
│   └── ☑ 骨架
└── 其他设置同上
```

## 与渲染器集成

### 动画加载

`src/renderer/pet/pet-animation.ts` 负责加载和播放动画：

```typescript
// 加载动画
const animation = await animationSystem.loadAnimation('idle');

// 播放动画
animationSystem.play('idle', { loop: true, fadeIn: 0.3 });

// 切换动画（自动过渡）
animationSystem.transitionTo('happy', { duration: 0.5 });
```

### 内置占位符

当动画文件不存在时，系统自动使用程序化动画：

- **idle**: 正弦波呼吸效果
- **happy**: 弹跳效果
- **thinking**: 左右摇摆
- **其他**: 基于 idle 的变体

## 故障排除

### 动画不播放
1. 检查文件是否存在于正确路径
2. 确认骨骼名称与模型匹配
3. 查看控制台错误信息

### 动画卡顿
1. 检查动画文件大小（应 < 500KB）
2. 确认帧率设置正确
3. 启用 Draco 压缩

### 动画扭曲
1. 确认骨骼层级结构匹配
2. 检查骨骼旋转顺序
3. 验证动画采样率
