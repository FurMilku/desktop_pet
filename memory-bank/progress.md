## 决策演变

### 2026-02-08
1. **初始需求**: 桌面3D小宠物（动物、植物、外星生物、可变形几何体）
2. **需求扩展**: 用户反馈需要AI大模型对接和工作助手功能
3. **方案调整**: 
   - 开发周期从10周扩展到15周
   - 新增AI智能层架构
   - 新增语音交互功能
   - 新增工具系统（Function Calling）

### 技术选型确认
- **推荐方案**: Electron + Three.js + LLM API
- **备选方案**: Tauri + WebGPU（性能更好但生态较新）
- **AI模型**: OpenAI API为主，Ollama本地模型为辅
